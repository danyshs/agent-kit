# when-to-ask

Claude does safe, undoable work without asking, leads with a recommendation instead of a menu, and runs every check once before saying "done".

    claude plugin install when-to-ask@agent-kit

## Parts

| Part | File | When it runs |
|---|---|---|
| Rule | `rules/when-to-ask.1.json` ([plain copy](../../rules/when-to-ask.md)) | In context from the start of every session |

Writes no files.
