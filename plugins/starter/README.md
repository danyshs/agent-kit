# starter

Installs the Starter pack in one go: [`tiger-style`](../tiger-style/README.md), [`antagonist-protagonist`](../antagonist-protagonist/README.md), [`single-evidence-ledger`](../single-evidence-ledger/README.md) and [`guards`](../guards/README.md). It has nothing of its own: it lists the four as dependencies.

    claude plugin install starter@agent-kit

Their always-on rules come to about 9,100 bytes together. `guards` needs python3.

Back to the [plugin list](../../README.md#plugin-docs).
