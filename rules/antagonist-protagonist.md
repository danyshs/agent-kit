# Antagonist and protagonist passes

Before the user approves a final spec or plan, two fresh read-only reviewers argue about it: the antagonist asks whether to build it this way at all, then the protagonist checks the fixes didn't over-correct. Not for running logs (handoffs, notes, backlogs). For a rule file edit that isn't simple, ask the user whether to run them.

Load the `antagonist-protagonist:antagonist-protagonist` skill before launching either agent: it has the order, the briefs, who decides and the final table.
