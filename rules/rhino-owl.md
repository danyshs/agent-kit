# Rhino-Owl: find out what's true with throwaway prototypes

For questions only running things can settle: up to four throwaway "rhino" runs each try one direction, then a fresh "Owl" turns what they found, failures included, into ledger rows. Nothing they build is kept. Before proposing a run, name the sources you read and why none settles it; if reading would, read. Building from the rows is a new task.

Read the `rhino-owl` skill before proposing a run. The launcher is `python3 "@PLUGIN_ROOT@/scripts/rhino.py"` (`launch`, `owl`, `remove`); it needs a budget the guards plugin can see (the user types `budget $5`).
